# Aesthetic Island Aesthetic Review & Recommendation Portal

This project is being developed for CISC 4900 at Brooklyn College.

The goal of this project is to create a web-based portal for Aesthetic Island where clients can submit aesthetic or skincare concerns for review by a nurse practitioner.

## Planned Features

- Client name and phone number submission
- Aesthetic or skincare concern submission
- Photo upload
- Secure nurse practitioner login
- View and manage client submissions
- Treatment or skincare recommendations
- Pricing and treatment information
- Pending and reviewed submission status

## Planned Technologies

- HTML
- CSS
- JavaScript
- React (possibly)
- Node.js
- Express.js
- PostgreSQL
- GitHub

## Status

Currently in the planning and early development stage.
